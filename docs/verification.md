# 1.4.0 公开版验证说明

本页记录 2026 年 10 月 12 日发布的 Knowledge Seed 1.4.0。公开版运行代码与此前通过验收的 1.4.0 相同，README 和发布包针对首次安装重新整理。

## 已完成的检查

- 严格 TypeScript 检查、实际插件构建、566 项自动回归全部通过。
- 在 Windows 的 Obsidian 1.14.4 中，通过真实界面检查新建原生图、后台增长、按起点找回、继续探索、查找并打开笔记、共享节点在单图移出和详细正文写回。
- 一个原先没有正文的概念在后台补入 6,285 个正文字符，保留原笔记和节点身份；正文包含 25 个结构块，并有导读与目录。
- 验收基线中的 3,935 篇原有 Markdown 和 6 篇普通测试笔记保持字节一致；10 张原有动态图的成员、路径、参数与移出记录保持。
- URL 起点标题不会被其他检索页面改成无关标题。新来源链接的目标与中文说明分开，单个网址引用不再被错误转义为另一个地址。

## 这些结果没有承诺什么

- 移动端及其他 Obsidian 版本没有在本轮实机验收。安装要求以 `manifest.json` 为准，首次使用建议桌面版。
- 公开检索目前来自 Wikipedia；指定网页使用静态 HTML 正文，不执行站点脚本，不能读取每一个网站。
- 起点和方向主要依名称、真实链接及正文中的词项匹配，不是模型语义判断。图中的一条线不自动代表因果关系或已核实的学术结论。
- 2,000 字符是正文保留目标，不是对原文长度的保证。来源短、不可达或没有可信匹配时保留实际内容及状态，不编造定义或凑字数。
- 取消与迟到写入等竞争条件同时使用受控异步回归验证；原生短任务在停止点击到达前已完成的情形，不算作实机中断成功证据。
- 公开 URL 检查基于字面主机及协议，并不提供 DNS 与所有最终重定向目的地的完整保证。请求不携带用户的网页登录凭据。

## 自己复查

开发者安装 Node.js 后，在源码目录运行：

```sh
npm ci
npm run check
```

这会检查类型、构建 `main.js` 并运行离线回归。它不能代替在你的 Obsidian 版本和网络环境中尝试实际操作。

真实公开页面的结构测试样本及来源署名见 [解析验证](parsing-quality.md) 和 [测试夹具许可](../tests/fixtures/NOTICE.md)。原生测试库、个人笔记、文件哈希清单、账户配置和本地 Git 历史不随公开仓库或安装包发布。
