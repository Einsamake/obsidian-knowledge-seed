# 0.14.3 开发测试版验证

代码检查日期：2026-10-18；实机验收日期：2026-10-19。基线为 0.14.2；版本沿用 0.14.x，历史发布保留。

## 改动

- 在原有文件菜单事件中增加图节点操作：以此节点为中心、查看关系与来源、后台补正文、剪除分支。
- 保留原有继续探索、剪除单个节点、打开所属图谱及原生菜单。
- 图节点菜单优先识别实际触发的已绑定图页签；共享节点无明确当前图时列出各图名称。
- 菜单执行前重新检查可见成员。起点不提供剪枝和补正文；剪枝不删除笔记，并维持其他图谱范围。
- 来源弹窗按纯文本显示原文，网页链接经过现有公共 URL 校验；打开来源弹窗不读取网络或启动探索。
- 正文任务入队后给出反馈；后台已暂停时明确提示从正文任务中继续，不擅自恢复全局后台阅读。

## 实机验证

用户手动完成新库信任后，在 Windows / Obsidian 1.14.4 的独立小型验收库中完成以下操作：

- 从图库打开已有三节点图；在原生画布的真实节点上点击鼠标右键，新增操作与 Obsidian 原有菜单同时显示。
- 点击“查看关系与来源”，正常显示该节点的两条关系、原文证据及来源网页入口；关闭后返回原图。
- 点击“以此节点为中心”，原生图切换到对应概念，当前图谱范围保持。
- 对共享概念执行“剪除分支（保留笔记）”，当前图由 3 节点 / 2 关系变为 1 节点 / 0 关系；另一个共享图仍为 3 节点 / 2 关系，成员、路径、参数、关系与剪枝范围保持。
- 两篇共享概念笔记仍存在，且与验收前内容逐字一致；全局后台阅读暂停设置保持。
- 起点节点右键不提供剪枝与补正文操作。

本轮使用离线小型材料，没有重新验收网络检索、完整正文抓取或长时间探索；正文入队反馈、暂停说明及过期菜单由自动回归覆盖。自动检查与实机菜单操作分别记录。

## 边界
